# Desarrollo
Cuanto estamos trabajando en temas matemáticos, ya sean matrices, ecuaciones, procesamiento  de señales, etc. Se utiliza cierta terminología para cada caso, esto nos ayuda a saber exactamente de que estamos hablando con solo ver la manera (Sintaxis) en la que fue escrita, hay muchos símbolos, ya que, te podrías encontrar con terminología parecida en otras temas de estudio como lo son Física, Química, [[Electronica]], Mecánica, aunque su significado puede ser totalmente diferente, por ellos, está nota iniciara con un apartado exclusivo de terminología para su mejor entendimiento dependiendo del problema que se este explorando.

## Terminología y notación
La variable `x` es sumamente utilizada en términos matemáticos, pero su significado dependerá del problema que se este trabajando.

### Derivadas

Una forma sencilla de entender la notación de sus derivadas es:

- `x` = Variable original
- `x'` = Primera derivada
- `x''` = Segunda derivada

### Movimiento Lineal

Cuando estamos trabajando con movimiento lineal, `x` representa la posición:

- `x` = Posición Lineal.
- `x'` = Velocidad Lineal.
- `x''` = Aceleración Lineal.

### Movimiento Rotacional

Para movimiento rotacional encontramos una notación similar:

- `θ (theta)` = Posición Angular.
- `ω (omega miniscula)` = Velocidad Angular.
- `α (alfa)` = Aceleración Angular.

Estas variables están relacionadas mediante:

- `ω` = `θ'`
- `α` = `ω'` = `θ''`

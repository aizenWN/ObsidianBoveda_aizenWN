# Desarrollo
## ¿De donde sale este archivo?
Este se genera cuando creamos un paquete en [[ROS]] 2 con la terminal:
```
ros2 pkg create --build-type ament_python rover_description
```
De tal forma que se crea:
- `setup.py` se crea automáticamente con la plantilla básica.

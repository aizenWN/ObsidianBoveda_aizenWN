# Sesión 2, 3 y 4
En cada una de estas sesiones, tocaremos las bases de cada una de las secciones del equipo, teniendo resultados tangibles en cada una de ellas para fomentar la emoción y dopamina por los resultados y así, observar el desempeño, afinidad y gusto por los temas trabajados

Cada una de las sesiones mencionadas se sentirá exclusivamente en las secciones (Programación, Electrónica, Diseño) con las posibles siguientes propuestas:

**Nota:** Al finalizar cada una de las sesiones, es importante recordar adjuntar avances al portafolio de evidencias en GitHub y llevarse una tarea / actividad a desarrollar en base a lo visto en la sesión. 

- *Programación*
Se explorarán las bases de la programación en C o C++,  se verán rápidamente conceptos ya vistos como tipos de datos, estructura básica (main), funciones, vectores, punteros, clases y objetos. 

Esto de manera equilibrada y no saturada para darle prioridad a nuestro resultado de la sesión, el cual será, llevarlo a [[Microcontroladores|microcontroladores]]. 

En esta segunda hora de sesión, se llevará a cabo el uso de un microcontrolador para imprimir mensajes en una pantalla oled, ya sea un texto o una carita, mediante el uso de Arduino, así se verán los resultados y motivaran a realizar cosas más exigentes. 

- *Diseño*
Se explorarán la interfaz de Fusión 360, herramientas básicas, cotas, bocetos, ejes de coordenadas y como moverse en el entorno, así como componentes, tipos de líneas, geometrías, patrones, simetrías y por último uniones o joint, para que el resultado de estas sesión, se pueda apreciar muy visualmente, el como tú diseño cobra vida

También se tocaran temas de como tener en cuenta lo aprendido para diseño 3D, tipos de formatos para exportación, capacidades de fusión y conocimiento de otros software CAD. 

- *[[Electronica]]*
En esta sesión, se entendera la electrónica básica, componentes básicos en la electrónica ([[Diodo Led|diodos led]], capacitores, [[Diodo|diodos]], resistencias, [[Transistor|transistores]], calibres de cables, baterias, reguladores), así como un repaso a la ley de ohms, calcular resistencia en base a voltaje para un led, trabajo en proto board, esto en la primera hora. 

Para la segunda hora se trabajará con diagramas, para que también entiendan como plasmar esta misma información, mediante everycircuit se llevará el circuito físico a lo virtual, para que completen su portafolio con ambas practicas y se lleven una experiencia y resultado real de ambos formatos.
